# dependency
It use the following dependencies.

+ dependencies related to `androidx.appcompat:appcompat`, including 

- `androidx.appcompat.app`
- `androidx.appcompat.content.res`
- `androidx.appcompat.graphics.drawable`
- `androidx.appcompat.view`
- `androidx.appcompat.widget`

For more details, see [`release of Appcompat class`](https://developer.android.com/jetpack/androidx/releases/appcompat)
