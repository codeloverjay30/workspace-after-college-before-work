# notice
## replication
When replication, you must follow the steps on [`Dependency injection with Hilt`](https://developer.android.com/training/dependency-injection/hilt-android)

After that, when sync, you may got this issue

```
Android 2 files found with path 'META-INF/gradle/incremental.annotation.processors'. error
```

To solve this issue, see issue section in `further_reading.md` attachment.
