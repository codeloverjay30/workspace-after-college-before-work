# README
## abstract
This demo project  

1. illustrate how to do `DI (dependency injection)` with `Hilt` (dependency that do DI)
2. provides simple use case of `DI` with `Hilt`.
3. illustrate the use of annotations about `DI`, such as `@Inject`, `@Module`, `@Binds`,`@InstallIn`, `@AndroidEntryPoint`,`@HiltAndroidApp`,.
